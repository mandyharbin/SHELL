📋 Overview

Central policy enforcement engine handling consent verification, emergency detection, forbidden intent classification, routing determination, pre-LLM sanitization, post-LLM validation, and audit event creation.

Server: https://api.ahp.internal (Internal cluster)

🔌 API Endpoints

🔒 Consent & Safety

GET /v1/consent/verify Consent
Verify whether user has granted data-backed AI consent.
Query Parameters:
* patient_id (string)
Response 200: ConsentResponse
• consent_granted (boolean)
• consent_id (string, nullable)
• timestamp (date-time)
POST /v1/emergency/detect Emergency Detection
Detect whether a message is an emergency using rules + ML.
Request Body: EmergencyDetectRequest
* patient_id (string)
* text (string)
• text_hash (string) - SHA-256 or similar hash
Response 200: EmergencyDetectResponse
• is_emergency (boolean)
• patterns (array of strings)
• confidence (number)
• text_hash (string)

🛡️ Core Guardrail Pipeline

POST /v1/guardrail/check Guardrails
Run full guardrail decision pipeline: consent check → emergency → forbidden → routing → allowed recommendation.
Request Body: GuardrailCheckRequest
* patient_id (string)
* text (string)
• context (object) - Sanitized context data
• message_id (string)
Response 200: GuardrailCheckResponse
• action (ActionType enum)
• action_reason (string)
• confidence (number)
• recommendation (object, nullable)
• audit_event_id (string)

📨 Routing & Audit

POST /v1/routing/create Routing
Create a routing ticket for staff inbox.
Request Body: RoutingCreateRequest
* patient_id (string)
* category (string) - e.g., "scheduling", "clinical", "billing"
* message_hash (string)
• metadata (object, nullable)
Response 200: RoutingCreateResponse
• routing_id (string)
• status (string)
• assigned_to (string, nullable)
POST /v1/audit/log Audit
Submit a signed audit event (tamper-evident event payload).
Request Body: AuditEvent
* event_type (string)
* message_id (string)
* timestamp (date-time)
• patient_id_hash (string)
• patterns (array of strings)
• confidence (number)
• action (ActionType enum)
• details (object, nullable)
Response 200: AuditResponse
• audit_id (string)
• status (string)

🏥 EHR Read-Only Adapter

GET /ehr/appointments/exists EHR Read-Only
Check if appointment exists for patient.
Query Parameters:
* patient_id (string)
Response 200: AppointmentExistsResponse
• exists (boolean)
• date (date, nullable)
GET /ehr/prescriptions/exists EHR Read-Only
Check if prescription exists for patient.
Query Parameters:
* patient_id (string)
Response 200: PrescriptionExistsResponse
• exists (boolean)

📊 Data Schemas

Enumerations

ActionType
Possible values:
EMERGENCY BLOCK ROUTE_PROMPT ROUTE_AUTOSEND ALLOW
HandoverReason
Possible values:
No Match Found Low Confidence Match Unsafe Clinical Question Requires Human Review Billing or Account Issue Ambiguous or Multi-Part Question
